# powerpoint-layers (Authoring stage)

Smart layers: a semantic shape grouping system with zero sidecar state. A
shape belongs to a layer when its native name ends with
`::layer=<name>` (e.g. `TextBox 4 ::layer=content`). Layer operations
edit the slide spTree XML directly, so they work on any PPTX — and every
deck generated by `powerpoint-deck` is tagged with the six built-in layers
already:

| Layer | Content | Typical use |
|---|---|---|
| background | full-slide background rects | restyle/replace the canvas |
| decoration | ghost circles, logos, hairlines | hide for clean/print variants |
| header | titles, section numbers, column heads | retitle / restyle headings |
| content | bullets, panels, cards, pictures | the editable payload |
| accent | accent rules, chips, timeline marks | instant rebrand by recolor |
| footer | deck-title footer, page numbers | hide or update footers |

## Workflow

1. `layer_list` first — inspect what layers exist before mutating
2. hide `decoration` (and optionally `background`) to produce a clean
   variant; restore with `visible: true`
3. `layer_recolor` on `accent`/`header` to rebrand a deck without
   touching content
4. `layer_assign` to tag hand-made or third-party decks so every later
   layer operation targets them

## Decision rules

- layer names match `^[A-Za-z][A-Za-z0-9_-]{0,31}$` — lowercase semantic
  names, keep the six built-ins for generated decks
- operations are all-slides by default; pass `slides` to scope them
- recolor only touches explicitly-set solid fills/lines — theme-inherited
  colors are skipped and reported, never guessed
- all mutating tools write in place unless `output` is given (a copy)

## Known limits

- z-order moves the layer's shapes as a block; interleaved per-shape order
  needs the `powerpoint-edit` patch engine
- hiding uses the native `hidden` attribute — PowerPoint keeps the shapes
  (recoverable, not deleted)

## Agent-visible summary

Layer inventory with per-slide shape names/ids/types/text previews, changed
shape counts per slide, and which colors were applied.
