# Deck IR recipes — powerpoint-deck

Ready-to-copy Deck IR documents (office-ir/1.0). Every layout in the
compiler registry has one minimal example here; copy the skeleton, keep
semantic_layout names exact, and fill in content. Never author slide
coordinates.

## Envelope skeleton

```json
{
  "schema_version": "office-ir/1.0",
  "kind": "presentation",
  "document_id": "draft:my-deck",
  "metadata": {"title": "My Deck", "author": "agent", "language": "zh-CN"},
  "template": {"uri": "brand://dcc-mcp", "version": "1.0.0"},
  "document": {
    "slides": [ ... ],
    "export_policy": {"pdf": true, "slide_previews": true}
  },
  "validation": ["no_text_overflow", "no_out_of_bounds"],
  "outputs": ["pptx", "pdf", "slide-previews"]
}
```

## Full working example

```json
{
  "schema_version": "office-ir/1.0",
  "kind": "presentation",
  "document_id": "draft:quick-deck",
  "metadata": {"title": "Quick Deck", "author": "agent", "language": "zh-CN"},
  "template": {"uri": "brand://dcc-mcp", "version": "1.0.0"},
  "document": {
    "slides": [
      {"semantic_layout": "title_cover", "title": "Quick Deck",
       "content_blocks": [{"type": "text", "paragraphs": ["generated by the agent"]}]},
      {"semantic_layout": "bullets", "title": "Why",
       "content_blocks": [{"type": "bullets", "items": ["fast", "contract-first", "editable"]}],
       "speaker_notes": "one takeaway per slide"},
      {"semantic_layout": "closing", "title": "Thanks"}
    ],
    "export_policy": {"pdf": true, "slide_previews": true}
  },
  "validation": ["no_text_overflow"],
  "outputs": ["pptx", "pdf", "slide-previews"]
}
```

## Notes

- bullet budgets: ≤ 6 bullets per slide, ≤ 80 chars per bullet
- images: BMP/GIF/JPEG/PNG/TIFF/WMF only — verify magic bytes, not
  extensions (WEBP gotcha); convert before embedding
- every picture carries alt text; image_grid captions come from resource ids
